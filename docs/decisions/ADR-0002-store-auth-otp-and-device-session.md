# ADR-0002: 店舗固定パスワード全廃とメールOTP＋30日端末セッション採用

Status: Accepted  
Date: 2026-09-11  

## Context
店舗スタッフは入れ替わりが激しく、店舗内で同一の固定パスワードを紙に書いて共有する運用では、退職したスタッフが外部から社内メニューや価格情報を継続して閲覧する危険があった。
一方で、強固な端末個別管理（WebAuthn、MDMクライアント証明書等）を導入すると、現場でタブレットが故障・交換されるたびに本社のIT担当者が現地へ駆けつけなければならず、100店舗以上の運用コストが破綻する。

## Decision
固定パスワードを完全全廃し、**「店舗専用メールアドレスによるワンタイムパスコード（OTP）」と「30日間の端末セッションCookie」の組み合わせ**を採用する。

1. **店舗名検索 & OTP発行**:
   - 店舗スタッフは画面で自店舗名を検索して選択する。
   - 登録された店舗通知用メールアドレス宛に、暗号学的6桁OTPを発行・送信（有効期限15分）。
   - コードはDBに平文保存せず、`HMAC-SHA256(challenge_id + ":" + otp, secret)` で保存。
2. **30日端末セッション**:
   - 検証成功時、端末に30日間有効な `HttpOnly`, `Secure` Cookieを付与。
   - 日常の営業中は再認証不要でメニューを開ける。
3. **リモート一括ログアウト**:
   - 端末紛失やスタッフ離脱時には、管理画面から店舗の `device_session_version` を更新することで、店舗内の全端末を即時無効化可能とする。

## Alternatives
- **月次固定パスワード変更運用**: 毎月パスワードを変えてスタッフへ周知する案。→周知の手間が大きく、変更直後に閲覧不能の問い合わせが殺到するため却下。
- **1通のメールに登録台数分のOTPを一括記載する案**: 当初検討されたが、どの端末がどのコードを使ったかの追跡が困難で、再送処理が複雑化するため、**「1端末ごとの要求につき1コード発行」**へ改訂・決定。

## Consequences
- **メリット**:
  - 退職者が外部からログインを試みても、店舗PC等でのみ受信可能な店舗メールを確認できないため不正ログインを阻止できる。
  - 本社担当者が店舗へ行かずに、店舗スタッフ自身で端末交換時の認証を完結できる。
- **デメリット / トレードオフ**:
  - 全店舗で確実に受信・確認できる店舗個別メールアドレスの事前登録が必須となる。
