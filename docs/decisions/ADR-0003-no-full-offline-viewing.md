# ADR-0003: 完全オフライン閲覧の禁止とセッション起動時検証

Status: Accepted  
Date: 2026-09-11  

## Context
ブラウザのIndexedDBに保存されたPDF Blobは、端末が完全にオフライン（機内モード等）である間、サーバー側から遠隔で削除することは技術的に不可能である。
もし「完全オフラインでの閲覧」を無制限に許可してしまうと、悪意のあるスタッフが失効済みの端末を持ち出し、機内モードのままメニューや価格情報を恒久的に閲覧・撮影できてしまうセキュリティリスクが生じる。

## Decision
**「完全オフラインでの閲覧は禁止（不許可）」**とする方針を確定した。

1. **起動時・閲覧前のセッション強制検証**:
   - アプリ起動時およびPDF表示前に、必ずオンラインでサーバー（`/api/store-auth/session`）へ問い合わせ、端末セッションの有効性を確認する。
2. **失効時の即時パージ**:
   - サーバーが失効（401）を返した場合、直ちにIndexedDB内のPDFキャッシュを全件削除（パージ）し、ログイン画面へ強制リダイレクトする。
3. **オフライン時のフェイルクローズ（Fail-Closed）**:
   - ネットワークが不達でセッション確認が完了しない場合、キャッシュが存在していてもPDFの描画を開始せず、「オンライン接続が必要です」を表示して停止する。

## Consequences
- **メリット**:
  - 本部で「一括ログアウト」や「端末失効」を実行した場合、次回端末がオンラインになった瞬間に確実にキャッシュが消去され、閲覧が即座に封殺される。
- **デメリット / トレードオフ**:
  - 店舗のWi-Fiが完全に遮断されている状況下では、一切メニューを表示できない（ナイトレジャー店舗では常時安定したWi-Fi提供が前提と合意）。
