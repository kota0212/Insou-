# ADR-0004: 端末識別におけるIP依存排除とHttpOnly Cookie採用

Status: Accepted  
Date: 2026-09-11  

## Context
店舗端末を識別・認証する手段として、店舗のIPアドレス固定や、ブラウザのlocalStorageへのトークン保存などが議論された。
しかし：
1. 店舗のインターネット回線は動的IPが多く、IPアドレスによるバインドは誤拒否や運用負担を招く。
2. localStorageやIndexedDBに認証トークンを平文保存すると、クロスサイトスクリプティング（XSS）脆弱性が発生した際にトークンを窃取される危険がある。

## Decision
1. **IPアドレスのみによる端末固定を排除**:
   - IPアドレスはレート制限や監査ログの参考情報としてのみ使用し、セッション認可の識別子としては使用しない。
2. **HttpOnly Cookie (`insou_store_session`) の採用**:
   - トークンは `HttpOnly`, `Secure`, `SameSite=Lax` 属性を付与したCookieとしてブラウザに保存。
   - JavaScriptスクリプトからトークン値自体にアクセスできないように保護。
3. **DBにはトークンのハッシュ（`token_hash`）のみ保存**:
   - 生トークンをDBに保存せず、万が一のDBダンプ漏洩時にもセッションハイジャックを防止。

## Consequences
- **メリット**:
  - XSSによるトークン盗難リスクを極小化。
  - 店舗Wi-Fiのルーター再起動やIP変動があっても端末セッションが維持される。
- **デメリット / トレードオフ**:
  - 複数オリジン間でのCookie送信制約（同一オリジンまたは適切なSameSite設定が必要）。
