# INSOU メニュー閲覧システム MVP仕様

## 1. 目的

MVPの目的は本番環境の完全再現ではなく、実際の業務フローと店舗側の操作性を確認することである。

```text
管理者 → PDF登録 → 閲覧対象店舗を指定 → 保存・公開
店舗 → ログイン → 割り当て済みPDFを直接表示
```

## 2. 技術構成

- Webアプリ：現在のNext.js MVP
- バックエンド：Google Apps Script（GAS）
- データ管理：Google Spreadsheet
- PDF本体：Google Drive
- 端末内PDF保存：IndexedDB
- 認証：画面遷移と業務フロー確認用のハリボテ認証

Spreadsheetでは店舗情報、メニュー情報、店舗とメニューの紐付けを管理する。PDF本体をSpreadsheetやlocalStorageへ保存しない。

## 3. 管理側機能

- PDF登録、一覧表示、更新、削除
- メニュー名等の管理
- 閲覧対象店舗の選択
- Google DriveへのPDF保存
- Google Spreadsheetへのメニュー情報・店舗紐付け保存
- 店舗ごとのログイン状況、最終ログイン日時、MVP用パスワード、パスワード最終更新日の確認

## 4. 店舗側機能

- 店舗専用URLのログイン画面
- ログイン後、割り当て済みPDFを一覧を経由せず直接表示
- アプリ内PDFビューア
- 前ページ・次ページ
- カードを後ろへ送るページ切替エフェクト
- ピンチ操作および `+` / `-` キーによる拡大・縮小
- 拡大中のパン移動
- `←` / `→` によるページ移動
- `0` による倍率・位置リセット
- 現在ページ / 総ページ数を右上に表示

店舗には運用上1件のメニューを割り当て、複数件ある既存データでは先頭の割り当てを表示する。未配信店舗のみ空状態を表示する。

## 5. MVPログイン状況とパスワード

店舗ログイン時にGASへ最終ログイン日時を記録し、管理者の店舗管理画面でログイン済み・未ログインと最終日時を確認できるようにする。MVP用パスワードと最終更新日も同画面に表示する。既存店舗には初期値 `1234` を設定する。

これはハリボテ認証の運用確認用であり、平文パスワード表示はMVP限定とする。本番では実装せず、Supabase Authで安全に管理し、管理者にも現在のパスワードを表示しない。

## 6. PDF取得と端末内保存

PDFはユーザーが通常ファイルとして操作できないWebアプリ専用領域（IndexedDB）へBlobとして保存する。

```text
初回：Google Drive → GAS経由で取得 → IndexedDBへ保存 → 表示
2回目以降：IndexedDBに同じ更新日時のPDFが存在 → 保存済みPDFを表示
更新時：updatedAtが変化 → 最新PDFを取得 → 同じメニューの旧キャッシュを置換
```

IndexedDBが利用できない、または容量不足の場合はPDF表示を止めず、ネットワーク取得したデータをセッション中のメモリで利用する。完全なオフライン対応はMVP対象外とする。

## 7. 全ページ先読み

PDFを開いた時点でPDF.js文書を1回だけ読み込み、全ページを順番にCanvasへ描画して保持する。ページ操作時は描画済みCanvasの表示を切り替えるため、ページ切替後の追加取得・追加描画を行わない。MVPでは2ページ程度のPDFを前提とし、非常にページ数の多いPDF向け最適化は行わない。

## 8. ページ番号UI

- PDFビューア右上へ配置
- `現在ページ / 総ページ数` 形式
- PDF本文を大きく隠さない半透明・角丸表示
- 従来より大きい18pxの文字で表示

## 9. 共有・ダウンロード制御

店舗側の通常操作には、ダウンロード、ファイル保存、共有、外部アプリ起動、Google Drive直接URL表示を設けない。IndexedDB内のPDFもWebアプリ内部データとして扱う。スクリーンショット等の完全防止は要件外とする。

## 10. MVP対象外

- Supabase Database / Auth / Storage
- Vercel本番デプロイ
- 本格認証、月次パスワード変更、Gmail通知
- 本番用セッション管理、RLS、Storage Policy
- 正式な利用ログ・PDF閲覧ログ
- PWA、Service Worker、完全オフライン対応
- 本番バックアップ・監視

## 11. MVP / 本番比較

| 項目              | MVP                    | 本番                |
| ----------------- | ---------------------- | ------------------- |
| 目的              | 業務フロー・操作性検証 | 実店舗で正式運用    |
| Webアプリ         | 現在のMVP              | Next.js             |
| デプロイ          | MVP環境                | Vercel              |
| バックエンド      | GAS                    | Supabase            |
| DB                | Spreadsheet            | Supabase PostgreSQL |
| PDF保存           | Google Drive           | Supabase Storage    |
| 認証              | ハリボテ               | Supabase Auth       |
| PW入力            | ハリボテ               | 月1回               |
| PW変更            | なし                   | 月1回自動変更       |
| PW通知            | なし                   | Gmailで自動送信     |
| 毎日ログイン      | 不要                   | 1日1回              |
| ログイン状態保持  | 不要                   | 約1か月             |
| 店舗別PDF表示     | 簡易                   | RLS等で正式制御     |
| PDF端末保存       | IndexedDB              | IndexedDB等         |
| PDF全ページ先読み | あり                   | あり                |
| ページ表示        | 右上に大きく表示       | 同様                |
| PDF共有           | UIなし                 | UIなし              |
| PDF更新同期       | `updatedAt`で簡易判定  | `version`等で管理   |
| オフライン        | 本格対応しない         | 対応                |
| 利用・閲覧ログ    | なし                   | あり                |
| 未利用店舗把握    | なし                   | あり                |
| バックアップ      | 不要                   | 本番要件            |
| 監視              | 不要                   | 本番要件            |
