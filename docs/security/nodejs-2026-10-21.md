# Node.js security update — 2026-10-22

- ID: NODE-SEC-20261021
- 根拠: https://nodejs.org/en/blog/vulnerability/october-2026-security-releases
- 修正版下限: 22.23.4 / 24.22.1 / 26.12.1。サポート終了系列は許容しない。
- 標準開発Node.jsは既存24系を維持し、.nvmrcを24.22.1へ固定。既存に許容されていたサポート中系列には系列ごとの修正版下限を設定。
- package-lock.jsonではルートenginesメタデータだけを同期し、依存パッケージのバージョンを変更しない。

## 検証

Node.js 24.22.1 / npm 11.19.1。標準npm ciは既存lockfileのpeer dependency不整合で失敗。npm ci --legacy-peer-deps --ignore-scriptsは成功。ビルド・全体Lintは負荷制御のため初回を中断、完了扱いにしない。

## 稼働環境と残作業

Vercelの24.x設定はパッチ版の実行証明ではない。本PRは設定修正のレビュー用であり、稼働環境が修正済みとは判定していない。Productionへのmerge/deployは未実施・本人承認待ち。Previewも実ランタイムのprocess.versionと主要画面/APIの確認後にのみ完了とする。
