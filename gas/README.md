# INSOU メニュー閲覧システム - Google Apps Script (GAS) バックエンド設定手順

本ディレクトリには、INSOU メニュー閲覧システム MVP のバックエンドとして機能する Google Apps Script (GAS) のコードが含まれています。

> **【注意: MVPのセキュリティについて】**  
> 本システムはMVP業務フロー検証用の実装です。ログイン機能はモック（ハリボテ認証）であり、本番運用に必要な認証トークン検証・暗号化・Row Level Security等の厳密なセキュリティ基盤は実装されていません。本番運用の際は `docs/production-spec.md` を参照してください。

---

## 1. Google側データ保存先について

SpreadsheetとGoogle DriveのPDF保存先は既存ファイルを流用しません。手順4で `INSOU_Menu_Master_MVP_日時` と `INSOU_Menu_PDFs_MVP_日時` を新規作成します。

---

## 2. GAS プロジェクトの作成とコードの配置

1. スプレッドシートの上部メニューから **「拡張機能」 > 「Apps Script」** を開きます（または [script.google.com](https://script.google.com) でスタンドアロンスクリプトを新規作成）。
2. プロジェクト名を設定します（例: `INSOU-Menu-Backend-MVP`）。
3. `Code.gs` の内容を本ディレクトリの `Code.gs` のコードで上書きします。
4. 左サイドバーの「プロジェクトの設定（歯車アイコン）」を開き、**「appsscript.json」マニフェスト ファイルをエディタで表示する** にチェックを入れます。
5. エディタに戻り `appsscript.json` を本ディレクトリの `appsscript.json` の内容で上書きします。

---

## 3. スクリプト プロパティの設定

左サイドバーの「プロジェクトの設定（歯車アイコン）」を開き、「スクリプト プロパティ」を追加します。

| プロパティ名 | 設定値 | 説明 |
|---|---|---|
| `SPREADSHEET_ID` | 設定不要 | 新規作成したSpreadsheetのIDが自動設定されます |
| `PDF_FOLDER_ID` | 設定不要 | 新規作成したPDF保存先のIDが自動設定されます |

---

## 4. 初期データベース（シート・シードデータ）の初期化

1. GASエディタで `Code.gs` を開きます。
2. 関数選択ドロップダウンから **`setupMvpResources`** を選択して実行します。
3. 初回実行時はアクセス権限の承認ダイアログ（「詳細」→「〜（安全ではないページ）に移動」→「許可」）が表示されるので承認します。
4. MVP専用のSpreadsheetと空のPDF保存フォルダが新規作成され、それぞれのIDが自動保存されます。同名の既存ファイルは検索・再利用しません。
5. 作成したSpreadsheetに以下の3シートと初期店舗データが登録されます。
   - `stores`: 店舗マスタ（店舗ID、コード、名称、エリア等）
   - `menus`: メニューマスタ（メニューID、タイトル、DriveファイルID、ファイル名、更新日時等）
   - `menu_stores`: メニューと店舗の割当テーブル（1店舗複数メニュー・複数店舗対応）

> `createNewPdfStorageFolder` を再実行すると、既存フォルダとその中のPDFを残したまま、新しい空の保存先へ切り替わります。

---

## 5. Web アプリケーションとしてデプロイ

1. GASエディタ右上の **「デプロイ」 > 「新しいデプロイ」** をクリックします。
2. 種類の選択（歯車アイコン）で **「ウェブアプリ」** を選択します。
3. 以下のとおり設定します:
   - **説明**: `MVP v1`
   - **次のユーザーとして実行**: **`自分` (me@example.com)**
   - **アクセスできるユーザー**: **`全員` (Anyone)** ※店舗端末や管理者ブラウザからAPIアクセス可能にするため
4. **「デプロイ」** をクリックします。
5. 表示された **「ウェブアプリ URL」**（例: `https://script.google.com/macros/s/.../exec`）をコピーします。

---

## 6. フロントエンド（Next.js）への環境変数設定

プロジェクトルートの `.env.local` ファイル（ない場合は作成）に以下を記述します:

```env
NEXT_PUBLIC_GAS_WEB_APP_URL="https://script.google.com/macros/s/xxxxxxxxxxxx/exec"
```

Next.jsの開発サーバーを起動または再起動すると、GAS APIとの連携が有効になります。
